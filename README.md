# AIMedX Single-Player Future-Ready Hospital Challenge

A static, GitHub Pages-ready simulation. No build process or dependencies are required.

## Package contents

- `index.html` — complete simulation, scoring logic and interface
- `assets/` — six capability visuals
- `README.md` — deployment and gameplay guide

## Game flow

1. **Project** — understand the 2030 opening, 2050 horizon and resource envelope.
2. **Future** — choose one strategic ambition.
3. **Capabilities** — select exactly three of six capabilities.
4. **Decisions** — for each capability choose Commit, Enable, Adapt, Avoid Lock-in or Defer.
5. **Your Hospital** — review how choices affect room, unit, facility, system and continuum.
6. **2040** — stress-test the combined portfolio.
7. **Results** — review what held, bent, broke and became future debt.

## Upload to GitHub Pages

1. Create a new public GitHub repository. Suggested name: `aimedx-single-player`.
2. Open the repository and choose **Add file > Upload files**.
3. Unzip this package on your computer.
4. Drag `index.html`, `README.md`, and the entire `assets` folder into the upload area.
5. Add a commit message such as `Launch AIMedX single-player simulation`.
6. Select **Commit changes**.
7. Open **Settings > Pages**.
8. Under **Build and deployment**, choose **Deploy from a branch**.
9. Select the `main` branch and `/ (root)` folder.
10. Save. GitHub will display the published site URL after deployment.

## Updating later

Upload replacement files using the same names. Keep the `assets` folder and file names unchanged unless the image paths in `index.html` are also updated.
