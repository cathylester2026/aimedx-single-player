# AIMedX Single-Player

React + Vite wrapper for the AIMedX Future-Ready Hospital Challenge.

## GitHub Pages

Repository name must remain `aimedx-single-player` unless `base` in `vite.config.js` is changed.

1. Upload all files and folders in this package to the repository root.
2. In GitHub, open **Settings > Pages**.
3. Under **Build and deployment > Source**, choose **GitHub Actions**.
4. Open **Actions** and select **Deploy AIMedX to GitHub Pages** if a manual run is needed.

The workflow builds the Vite app into `dist` and deploys the artifact to GitHub Pages.
